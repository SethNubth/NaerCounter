📦 Instalación

1. Descarga la carpeta `NaerCounter`
2. Extrae en: `World of Warcraft\Interface\AddOns\`
3. Verifica que quede así:
AddOns\NaerCounter\NaerCounter.toc
AddOns\NaerCounter\*.lua
AddOns\NaerCounter\textures\
4. Activa en selección de personaje

🎮 Comandos

/nc - Abrir configuración
/nc routes - Ver rutas
/nc reset - Reiniciar contador
/reload - Recargar si sale ? verde
